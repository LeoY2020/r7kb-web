还没有问答

FAQ 的价值在于「一次写好，反复使用」。在 content/faq/ 里按分类建 Markdown 文件，从最近班会里被问最多的三个问题开始最省力。

在 content/faq/ 里添加第一条

{
  id: 'faq-001',
  question: '错题本该怎么用才有效？',
  answer: '每道错题只记三件事：错因、正确思路、同类题一道。',
  category: '方法',
}

整理原则

  • 同题只收一次

    同一个问题被问第二遍时，就把回答搬进来，下次直接发链接。

  • 回答写成可执行的动作

    少写「注意一下」，多写「周五 20:00 前交到学习委员处」。

  • 挂上分类

    按「作业 / 考试 / 方法 / 活动」分目录，问题一多也不会乱。
