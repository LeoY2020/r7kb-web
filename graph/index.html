怎么添加概念

  1. 1

    先在 content/graph/subjects/ 建学科

    每门学科一个 Markdown，写 id 与颜色。

  2. 2

    再登记概念节点

    写 label、summary、level。

  3. 3

    用 prerequisites 连边

    填前置概念的 id，图谱会自动画箭头。

{
  id: 'linear-function',
  label: '一次函数',
  prerequisites: ['coordinates'],
}

为什么用有向图？

先修的箭头指向后学的概念。复习时沿箭头倒推，就知道自己卡在哪一步，而不是把整章重看一遍。

提示：图谱必须是无环的（概念 A 不能绕回自己）

维护约定

一个概念一个文件

写在 content/graph/concepts/ 里，目录层级（基础/进阶/拓展）会自动成为图谱层级。

一条边 = 一条依赖

只有当「不先学 A 就学不懂 B」时才写 prerequisites，弱相关别连。

必须无环

如果绕一圈回到自己，说明拆得不够细，先把概念拆开。
