怎么维护这张图

  1. 1

    笔记存在就上墙

    知识库里任何一篇笔记都会成为节点；章节目录的 index.md 标题会自动作为节点名。

  2. 2

    在 chapter-links.json 连边

    prerequisites 是前置，next 是下一章，related 会画成虚线。

  3. 3

    构建期校验

    指向不存在的章节或绕成环，构建都会直接报错并指出位置。

{
  "ch-02": {
    prerequisites: ['ch-01'],
    next: ['ch-03'],
    related: ['ch-04']
  }
}

为什么按章节连？

先修的箭头指向后学的章节。复习时沿箭头倒推，就知道自己卡在哪一步，而不是把整章重看一遍。

维护约定

节点来自章节

content/knowledge/ 里每个章节目录的 index.md 就是一个节点，标题与描述自动同步。

边写在 chapter-links.json

在 content/knowledge/_config/chapter-links.json 里写 prerequisites / next / related。

引用必须存在且无环

指向不存在的章节、或先修关系绕回自己，构建都会直接报错并指出位置。
