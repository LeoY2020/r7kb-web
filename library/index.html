资料库还是空的

课件、讲义、复习提纲都可以放进来。文件本体放 public/resources/，条目登记在 content/library/。

在 content/library/ 里添加第一条

{
  id: 'r-001',
  title: '第一单元复习提纲',
  subjectId: 'math',
  type: 'pdf',
  href: '/resources/unit-1-review.pdf',
  size: '1.2 MB',
  updatedAt: '2026-03-01',
}

文件放 public/resources/

按「学期-学科-单元」建子目录，文件名不要用「最终版」「真的最终版」。

条目写进 content/library/

每份资料一个 Markdown 文件，frontmatter 里登记 href、类型与更新时间。

只放能直接用的

能直接下载、直接打印、直接背的资料优先，半成品放草稿区。
